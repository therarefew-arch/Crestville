# Your music

Drop audio files here to replace the game's synthesized music. Unity imports mp3, ogg and wav.

| File name (any extension) | Plays during |
|---|---|
| `investigation` | The investigation on foot, the intro and the epilogue |
| `fight` | The street brawl and the robot fight |

For example, save your Suno track "Smoky Piano" as `investigation.mp3` in this folder.
Tracks loop, so a track that ends cleanly on its last beat loops best.
If no file is here, the game uses its own synthesized music.
